MSc January Intake Final Project - "Digital Shadow of Drumfos centrifugal pump for performance monitoring and fault detection"

## Overview

The project uses experimentally collected centrifugal pump data to build a software-based representation of healthy pump behaviour and support performance monitoring and anomaly detection.

The system processes electrical and vibration measurements, extracts signal features, builds healthy operating baselines, and exposes the processed data through a software architecture suitable for future digital-model visualisation.

## Project Pipeline

1. Raw Experimental Data
2. Data Ingestion & Validation     
3. Feature Extraction     
4. Processed Measurements     
5. Per-Run Healthy Baselines     
6. Setpoint Healthy Baseline
7. Anomaly Detection / Digital Shadow
8. Machine Learning Fault Classifier
